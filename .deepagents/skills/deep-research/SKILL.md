# Deep Research Skill

Use this skill to conduct comprehensive research on complex topics using multiple research agents and perspectives.

## Best Practices

- Break complex topics into researchable sub-questions
- Gather information from diverse authoritative sources
- Cross-reference findings to verify accuracy
- Document assumptions and uncertainty
- Synthesize findings into coherent, actionable insights

## Process

1. **Define the research scope** - What aspect of the topic needs deep investigation?
2. **Decompose the question** - Break into smaller, researchable components
3. **Multi-agent research** - Deploy specialized agents to investigate different angles:
   - Technical deep dive agent
   - Historical/contextual agent
   - Expert perspectives agent
   - Practical applications agent
4. **Synthesize findings** - Combine insights from all agents
5. **Validate and refine** - Check for contradictions and fill gaps
6. **Create comprehensive summary** - Document findings with sources and confidence levels

## Research Dimensions

- **Technical**: Architecture, implementation, technical details
- **Historical**: Background, evolution, key milestones
- **Expert opinions**: What do thought leaders say?
- **Practical applications**: How is this used in the real world?
- **Future outlook**: Where is this heading?

## Common Pitfalls

- Don't rely on single sources for complex topics
- Avoid confirmation bias - actively seek contradicting viewpoints
- Don't present opinions as facts
- Don't neglect to document uncertainty and limitations
