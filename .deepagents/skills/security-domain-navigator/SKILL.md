# Security Domain Navigator

Quick-reference index: given a task or domain, find the best resource from the Awesome-Hacking ecosystem.

## By Task

### "I need wordlists / payloads"
- **[SecLists](https://github.com/danielmiessler/SecLists)** — passwords, usernames, DNS, URLs, web content, fuzzing
- **[PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings)** — web attack payloads with bypass techniques
- **[Probable Wordlists](https://github.com/berzerk0/Probable-Wordlists)** — sorted by probability, great for password cracking
- **[Payloads (foospidy)](https://github.com/foospidy/payloads)** — additional web attack collection

### "I need to crack a password / hash"
- **[Awesome Password Cracking](https://github.com/n0kovo/awesome-password-cracking)** — tools and techniques
- **[Probable Wordlists](https://github.com/berzerk0/Probable-Wordlists)** — high-probability wordlists
- **[SecLists /Passwords/](https://github.com/danielmiessler/SecLists)** — common password lists

### "I need to analyze malware / a suspicious binary"
- **[Awesome Malware Analysis](https://github.com/rshipp/awesome-malware-analysis)** — sandbox, static/dynamic analysis tools
- **[YARA](https://github.com/InQuest/awesome-yara)** — detection rules, tools, and community rules
- **[Awesome Reversing](https://github.com/HACKE-RC/awesome-reversing)** — RE from scratch
- **[Reverse Engineering Reading List](https://github.com/onethawt/reverseengineering-reading-list)** — articles, books, papers
- **[Executable Packing](https://github.com/packing-box/awesome-executable-packing)** — packers/unpackers
- **[CyberChef](https://gchq.github.io/CyberChef/)** — decode/deobfuscate in browser

### "I'm doing web app security testing"
- **[Awesome Web Hacking](https://github.com/infoslack/awesome-web-hacking)** — web vuln resources
- **[Awesome AppSec](https://github.com/paragonie/awesome-appsec)** — application security learning
- **[PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings)** — payloads by vuln type
- **[OWASP CheatSheetSeries](https://github.com/OWASP/CheatSheetSeries)** — secure coding + remediation
- **[Web Security (qazbnm456)](https://github.com/qazbnm456/awesome-web-security)** — deeper material

### "I'm doing API security testing"
- **[API Security Checklist](https://github.com/shieldfy/API-Security-Checklist)** — design, test, release checklist
- **[Awesome AppSec](https://github.com/paragonie/awesome-appsec)** — broader application security

### "I'm doing network / infrastructure testing"
- **[Awesome Pentest](https://github.com/enaqx/awesome-pentest)** — full pentest toolset
- **[Pcaptools](https://github.com/caesar0301/awesome-pcaptools)** — packet capture analysis
- **[Honeypots](https://github.com/paralax/awesome-honeypots)** — detect adversaries on your network
- **[Suricata](https://github.com/satta/awesome-suricata)** — IDS/IPS rules and resources

### "I'm researching a threat actor / incident"
- **[Awesome Threat Intelligence](https://github.com/hslatman/awesome-threat-intelligence)** — feeds, platforms, frameworks
- **[APT Notes](https://github.com/kbandla/APTnotes)** — public docs on APT campaigns
- **[IOC](https://github.com/sroberts/awesome-iocs)** — indicator of compromise sources
- **[ThreatHunter-Playbook](https://github.com/OTRF/ThreatHunter-Playbook)** — hunting hypotheses and techniques
- **[Awesome Incident Response](https://github.com/meirwah/awesome-incident-response)** — IR tools and frameworks

### "I'm doing threat hunting / detection engineering"
