# Browser Research Skill

Use this skill to automate web browsing, research URLs, and gather information from websites.

## Best Practices

- Always specify the exact URL or search term clearly
- Break complex research into multiple focused requests
- Validate information from multiple sources when possible
- Save important findings to memory for future reference

## Process

1. **Understand the request** - What URL or topic does the user want to research?
2. **Navigate and gather** - Use browser automation to visit URLs and extract relevant information
3. **Synthesize findings** - Compile the information into a coherent summary
4. **Save results** - Store important findings in memory or notes

## Common Pitfalls

- Avoid scraping without respecting robots.txt and site policies
- Don't assume first search results are authoritative - verify information
- Don't attempt to bypass authentication systems
